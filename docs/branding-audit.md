# Branding audit

Upstream branding still visible to users in a Synapse build of Code - OSS 1.147.0: after the patches, the `product.json` merge and the build's rebrand step (`build/rebrand.mjs`, which turns "VS Code" into the product name). What is left on purpose: phrases naming Microsoft's real products (VS Code for the Web, the Stable and Insiders editions, the VS Code marketplace) and "Microsoft" where it means Microsoft's own services or extensions. The built-in GitHub Copilot is not shipped and not counted. Generated by `node build/audit-branding.mjs`; comments, copyright headers and tests are excluded.
